# 採用適性診断

新卒・中途の採用選考で使う、性格・価値観（カルチャーフィット）・能力の診断アプリです。1枚のHTMLで動く試作版です。

## 内容

| 部 | 内容 |
|---|---|
| 性格 | ビッグファイブ（外向性・協調性・誠実性・情緒安定性・開放性）、20問、5段階 |
| 価値観 | 6項目＋新卒は「基礎習得」、中途は「環境適応」。自社の目標プロフィールとの近さを表示 |
| 能力 | 言語・論理・数的、各4問の計12問、制限時間12分（新卒・中途で別問題） |

管理画面では、結果の一覧・詳細、CSV書き出し、目標プロフィールの設定ができます。

## ファイル構成

- `index.html` 組み立て済みの完成版（これ1枚で画面が表示されます）
- `src/data.js` 設問、選択肢、目標プロフィールの初期値
- `src/app-*.js` 画面と採点の処理
- `src/style.css` 見た目
- `build.py` `src/` から `index.html` を作り直す（`python3 build.py`）

設問を直すときは `src/data.js` を編集し、`build.py` を実行してください。

## 動作の前提

回答の保存、結果の一覧、CSV書き出しは、claude.ai のアーティファクトの機能（データ保存、閲覧者の権限、ファイル保存）を使っています。このHTMLを他の場所に置いても画面は表示されますが、回答は保存されません。診断として使うときは、claude.ai に公開したページを使ってください。

## 設問の出典と注意

- 性格の設問は、パブリックドメインの IPIP（International Personality Item Pool）のビッグファイブ設問から20問を選び、日本語に訳したものです。翻訳の確認は済んでいません。
- 価値観と能力の設問は自作で、市販の検査の問題は写していません。
- 入社後の活躍との関連は検証されていません。結果は面接を補う参考情報として使い、合否を結果だけで決めないでください。
- 氏名と回答は個人情報です。利用目的の明示、閲覧者の限定、保管期間の設定が必要です。
